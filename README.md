# Кубомёт

Калькулятор бросков и проверок D&D 5e (редакция 2014). Работает целиком в браузере: без установки, без интернета, без прав администратора.

## Запуск

1. Распакуйте архив в любую папку.
2. Откройте файл `index.html` двойным щелчком мыши.
   Если файл открылся не в браузере, нажмите на нём правой кнопкой, выберите "Открыть с помощью" и укажите браузер.

## Возможности

- Лист персонажа: шесть параметров, уровень, бонус мастерства, владения навыками и спасбросками, класс защиты, хиты, скорость, заклинательный параметр, список оружия.
- Семь типов бросков: проверка навыка, спасбросок, инициатива, атака оружием, атака заклинанием, урон, произвольная формула.
- Преимущество и помеха для бросков d20.
- Сравнение результата с целевым числом (DC или КЗ) и вердикт.
- Критическое попадание на 20 и автоматический промах на 1.
- Удвоение кубиков урона при критическом попадании.
- История последних 20 бросков с раскладкой арифметики.
- Светлая и тёмная тема.

## Как пользоваться

1. Заполните лист персонажа в левой колонке. Модификаторы и бонус мастерства считаются автоматически, сохранять ничего не нужно, данные записываются сами.
2. В правой колонке выберите тип броска.
3. Укажите навык, параметр, оружие или формулу, в зависимости от типа.
4. При необходимости выберите преимущество или помеху.
5. Заполните целевое число (DC или класс защиты цели). Поле необязательное: если его оставить пустым, приложение покажет результат броска без вердикта.
6. Нажмите "Бросить".

В поле формулы поддерживается запись вида `3d4+d8-1`. Доступные кубики: d2, d3, d4, d6, d8, d10, d12, d20, d100. В этом поле работает клавиша Enter.

## Хранение данных

Персонаж, история бросков и выбранная тема сохраняются в самом браузере и восстанавливаются при следующем открытии файла.

- Данные привязаны к конкретному браузеру на конкретном компьютере. Перенос персонажа на другой компьютер не поддерживается.
- Кнопка "Сбросить персонажа" очищает лист и историю.
- Если браузер работает в режиме инкогнито или запретил сохранение, приложение продолжит работать, но вверху появится предупреждение, что данные будут потеряны при закрытии.

## Ограничения

Приложение не содержит книги заклинаний, инвентаря, учёта текущих хитов и состояний. Поддерживается один персонаж. Приложение не передаёт никаких данных по сети.
